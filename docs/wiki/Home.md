# Irreducible

**Ask a harder question. Keep the calculation honest.**

Irreducible is an agent-operated scientific engine being built around explicit equations, native numerical kernels and reproducible run identities. Its executable is **`irred`**. It is in early development; current foundation commands do not yet constitute an end-to-end cosmological inference system.
