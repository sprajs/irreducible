# Retained Gaussian design profile (C++ only)

`irred/statistics.hpp` and `irred/gaussian_design.hpp` supply a library-first bounded linear prerequisite. This has no CLI/C ABI/Rust route. Named synthetic linear tests do not implement a distance ladder, recover H₀ or qualify released observations.

For supplied residual vector r, fixed design X and supplied positive-definite covariance C, the calculation minimizes q=(r−Xβ)ᵀC⁻¹(r−Xβ). It reports β, adjusted residuals, q and the **relative** score −q/2. There is no determinant/normalization term, integration measure over β, evidence or normalized density. A fitted coefficient covariance is not a generative prior. Prior-bearing Gaussian objects are rejected: a normalized multi-parameter proper-prior route requires a separate future contract.

## Identity and units

X is finite row-major n×p, n≥p≥2. Exact ordered row IDs must match the consumed Gaussian. Parameter IDs are unique and ordered, each with an explicit unit; residual unit, design identity and dependence identity must be nonempty. X column j has residual-unit/parameter-unit dimensions. Covariance axes have residual-unit squared dimensions. Unit labels and declared dependence are caller provenance, not automatically verified physical conversions. Shared nuisance IDs are a unique exact subset of parameter IDs: one shared zero point is one column spanning its declared rows, never independent copies inferred by row. Empty shared IDs explicitly declare no named shared parameters. Existing Gaussian covariance/precision preparation, selection, arithmetic and source provenance survive unchanged.

## Numerical domain and rank

Both preparation and evaluation require round-to-nearest arithmetic (`FE_TONEAREST`) and long double with at least 64 mantissa bits and maximum exponent at least 16384, including when the retained covariance factor uses binary64 arithmetic. Unsupported environments return `unsupported_domain` with no calculation payload; failed preparation leaves the Gaussian source usable.

Preparation uses existing covariance solves once per column and retains that same factor. Columns are equilibrated by their C⁻¹ metric norms. The retained Gram matrix is G=D⁻¹XᵀC⁻¹XD⁻¹. Existing Cholesky and solves operate on G; dot products accumulate in long double, while input/output and design storage is binary64. This forms normal equations and **squares the whitened design conditioning**. It is not a QR/SVD rank certificate.

Full column rank is reported only *within the conditioning admission contract*: G must pass Cholesky and κ∞(G) ε_binary64 ≤ min(10⁻⁸, requested maximum_forward_sensitivity). The condition value is an arithmetic estimate from the retained factor, not a rigorous bound. An exact all-zero column establishes deficiency. Other factor/conditioning failures report unresolved rank, withhold outputs and preserve the source. No jitter, regularization or dropped columns repairs failure. Column rescaling improves coordinate robustness but does not resolve geometric near-dependence. Qualifying general ill-conditioned rank would need a separately reviewed stable rank-revealing algorithm.

Evaluation solves for β without refactorization. **Reported binary64 coefficients define the adjusted residuals**: wide subtraction r−Xβ is rounded to binary64, then the actual rounded residual is solved against C. q and the relative score use that residual. The reported normal-equation defect is max_j |(X_j/D_j)ᵀC⁻¹e| divided by max_j Σ_i |(X_ij/D_j)(C⁻¹r)_i|; when the denominator is zero its absolute numerator is used. Admission requires this actual post-cast defect ≤ the requested sensitivity budget, independently of the earlier Gram solve. Covariance-solve backward residual and estimated forward sensitivity refer to the adjusted residual solve. Nonzero coefficient/residual/objective outputs require normal binary64; underflow, overflow and nonfinite results fail with no usable vector payload. These are arithmetic diagnostics, not inference or posterior qualification.

## Ownership and resources

`DesignProfile::prepare(std::move(gaussian), X, row_ids, metadata, policy)` consumes the source only after successful preparation. Failure leaves it usable. The covariance factor is moved once, covariance storage is released, and provenance/selection are moved without a whole-matrix copy or readback. `DesignProfile` is move-only; moving invalidates the source, and self move assignment preserves it. Evaluate retains no caller buffers and never changes the owner.

`preparation_payload_bound` is a conservative simultaneous payload envelope containing the source, candidate metadata, X storage and preparation-local C⁻¹X scratch, Gram factor/condition scratch and solve scratch. `maximum_elements` bounds n×p and p×p before allocation; `maximum_payload_bytes` admits the preparation envelope. `evaluation_payload_bound` separately bounds serial scratch plus returned vectors, excluding retained state and borrowed inputs; evaluate checks that envelope and n,p before allocating. `retained_payload_bound` reports owned capacities including metadata. Bounds exclude allocator bookkeeping and RSS, and do not promise whole-process memory limits. Work is O(p n²+p²n+p³) preparation and O(n²+np+p²) evaluation; retained payload is O(n²+np+p²), scratch O(n+p) per evaluation. All evaluation calls are serial in the resource contract.

## Named evidence and limitations

Owner tests freeze coefficient/residual tolerance 2×10⁻¹² absolute plus relative, quadratic 10⁻¹⁰ absolute, with 10⁻¹² independent small exact references. The synthetic two-anchor/host/shared-zero-point control has orthogonal contrasts and a shared column; the peer suite independently solves augmented KKT equations for correlated-covariance controls, avoiding a Gram-only oracle. Tests challenge row/parameter order, shared identities, units, exact and near rank deficiency, moves, priors, resource limits, nonfinite inputs and post-cast diagnostics. This is bounded evidence for those named cases, not an all-domain scientific qualification, actual calibration analysis or joint ladder fit.
