# Retained Gaussian design profile (C++ only)

`irred/statistics.hpp` and `irred/gaussian_design.hpp` supply a library-first bounded linear prerequisite. This has no CLI/C ABI/Rust route. Named synthetic linear tests do not implement a distance ladder, recover H₀ or qualify released observations.

For supplied residual vector r, fixed design X and supplied positive-definite covariance C, the calculation minimizes q=(r−Xβ)ᵀC⁻¹(r−Xβ). It reports β, adjusted residuals, q and the **relative** score −q/2. There is no determinant/normalization term, integration measure over β, evidence or normalized density. A fitted coefficient covariance is not a generative prior. Prior-bearing Gaussian objects are rejected: a normalized multi-parameter proper-prior route requires a separate future contract.

## Identity and units

X is finite row-major n×p, n≥p≥2. Exact ordered row IDs must match the consumed Gaussian. Parameter IDs are unique and ordered, each with an explicit unit; residual unit, design identity and dependence identity must be nonempty. X column j has residual-unit/parameter-unit dimensions. Covariance axes have residual-unit squared dimensions. Unit labels and declared dependence are caller provenance, not automatically verified physical conversions. Shared nuisance IDs are a unique exact subset of parameter IDs: one shared zero point is one column spanning its declared rows, never independent copies inferred by row. Empty shared IDs explicitly declare no named shared parameters. Existing Gaussian covariance/precision preparation, selection, arithmetic and source provenance survive unchanged.

## Numerical domain and rank

Both preparation and evaluation require round-to-nearest arithmetic (`FE_TONEAREST`) and long double with at least 64 mantissa bits and maximum exponent at least 16384, including when the retained covariance factor uses binary64 arithmetic. Unsupported environments return `unsupported_domain` with no calculation payload; failed preparation leaves the Gaussian source usable.

Preparation uses the retained covariance Cholesky factor C≈LLᵀ directly, with forward triangular whitening z=L⁻¹r. It does not solve C⁻¹X or form normal equations. Each design column is normalized in wide arithmetic: D_j=maxabs(X_j)‖L⁻¹(X_j/maxabs(X_j))‖₂, A=L⁻¹XD⁻¹. Preparation retains a column-pivoted Householder factorization AP=QR, the normalized whitened A for actual-output stationarity checks, and the original binary64 X. Trailing norms are recomputed when choosing pivots, avoiding cancellation-prone norm downdates. The compact reflectors and triangular R are retained across evaluations. QR arithmetic is long double regardless of the source covariance-factor arithmetic; `arithmetic()` continues to identify that source arithmetic. `method_id()` is `retained-whitened-pivoted-householder-qr/v1`, and `qr_arithmetic_id()` is `longdouble-cpu/v1`.

`equilibrated_triangular_condition_inf()` reports κ∞(R)=‖R‖∞‖R⁻¹‖∞ in the scaled, pivoted coordinates, estimated by retained triangular solves. This is not a squared Gram proxy, a rigorous bound, or an SVD κ₂(A); Q preserves the 2-norm, not the infinity norm. Full column rank is reported only **within the conditioning admission contract**: κ∞(R)[ε_binary64+(n+p)ε_longdouble]≤min(10⁻⁸, requested maximum_forward_sensitivity). A trailing pivot norm ≤(n+p)ε_longdouble with normalized columns is unresolved rank and withholds outputs. An exact all-zero original column establishes deficiency. Other factor/conditioning failures report unresolved rank and preserve the source. No jitter, regularization or dropped columns repairs failure. Column rescaling improves coordinate robustness but does not resolve geometric near-dependence.

The bounded `numerics::whiten` helper borrows the factor and right-hand side without copying/readback of the covariance. It returns wide coordinates with a normwise backward residual ‖Lz−r‖∞/(‖L‖∞‖z‖∞+‖r‖∞) against **stored L** (zero when both norms vanish), and an arithmetic rounding estimate equal to that residual plus nε_longdouble. These are empirical triangular arithmetic diagnostics, not a covariance-conditioned forward-error guarantee or a certificate of the source factorization. Their estimate must satisfy the requested policy. Failure has no vector payload. Both binary64 and wide factor storage are supported, with wide triangular arithmetic in either case. Reference comparisons must additionally test the supplied covariance calculation.

Evaluation whitens r, applies the retained reflectors and back-solves R without refactorization. **Reported binary64 coefficients define the adjusted residuals**: wide subtraction r−Xβ is rounded to binary64, then that actual residual is whitened. The actual q=‖L⁻¹e‖₂² and relative score −q/2 use that residual; neither is inferred from a canceled difference of pre-fit quadratics. The reported `normalized_normal_equation_residual` is max_j |A_jᵀL⁻¹e| divided by max_j Σ_i |A_ij(L⁻¹r)_i|; when the denominator is zero its absolute numerator is used. This is the same stationarity equation in whitened coordinates, with an explicitly changed normalization from the old C⁻¹-product metric. Admission requires the actual post-cast defect ≤ the requested sensitivity budget. `covariance_whitening_backward_residual` and `covariance_whitening_rounding_estimate` report the adjusted-residual whitening diagnostics. Nonzero coefficient/residual/objective outputs require normal binary64; underflow, overflow and nonfinite results fail with no usable vector payload. Wide whitening/QR coordinates require finite normal or zero values. These are arithmetic diagnostics, not inference or posterior qualification.

## Ownership and resources

`DesignProfile::prepare(std::move(gaussian), X, row_ids, metadata, policy)` consumes the source only after successful preparation. Failure leaves it usable. The covariance factor is moved once, covariance storage is released, and provenance/selection are moved without a whole-matrix copy or readback. `DesignProfile` is move-only; moving invalidates the source, and self move assignment preserves it. Evaluate retains no caller buffers and never changes the owner.

`preparation_payload_bound` is a conservative simultaneous payload envelope containing the source, candidate metadata, original X, wide A and QR storage, and preparation-local whitening/condition scratch. `maximum_elements` bounds n×p and p×p before allocation; `maximum_payload_bytes` admits the preparation envelope. `evaluation_payload_bound` separately bounds serial whitening/reflector/backsolve scratch plus returned vectors, excluding retained state and borrowed inputs; evaluate checks that envelope and n,p before allocating. The whitening helper also checks its vector payload bound and n before allocation. `retained_payload_bound` reports owned capacities including metadata. Bounds exclude allocator bookkeeping and RSS, and do not promise whole-process memory limits. Work is O(p n²+n p²+p³) preparation and O(n²+np+p²) evaluation; retained payload is O(n²+np), scratch O(n+p) per evaluation. All evaluation calls are serial in the resource contract.

## Named evidence and limitations

Owner tests freeze coefficient/residual tolerance 2×10⁻¹² absolute plus relative, quadratic 10⁻¹⁰ absolute, with 10⁻¹² independent small exact references. The synthetic two-anchor/host/shared-zero-point control has orthogonal contrasts and a shared column; the peer suite independently solves augmented KKT equations for correlated-covariance controls, avoiding a Gram-only oracle. A separate exact dyadic two-column control uses X=(1,1+2⁻¹⁴t), t=(−3,−1,1,3), and analytically derived coefficients/residuals/q; its reference was also checked by a separate 90-digit direct SVD calculation before production comparison. Ordinary tests require only the frozen analytic facts, not an external SVD dependency. Tests challenge row/parameter order, shared identities, units (including powers-of-two scaling by ±900), exact and near rank deficiency, moves, caller-buffer lifetime, priors, byte/element resource boundaries, unsupported rounding, nonfinite inputs and actual post-cast stationarity. This is bounded evidence for those named cases, not an all-domain scientific qualification, actual calibration analysis or joint ladder fit.
