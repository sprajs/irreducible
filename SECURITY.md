# Reporting a security problem

For a vulnerability that could expose private data, corrupt records or execute unintended code, use [GitHub's private vulnerability reporting](https://github.com/sprajs/irreducible/security/advisories/new). Include the affected commit, a minimal reproduction and the impact. Avoid putting credentials, private datasets or sensitive exploit details in a public issue.

Ordinary bugs and numerical discrepancies belong in [issues](https://github.com/sprajs/irreducible/issues). State the expected behavior, input domain and observed result.

Irreducible is in early development. Security fixes target the current main branch; there is no supported release series or guaranteed response time yet. Research inputs should be treated as untrusted, and scientific model changes should go through source review and rebuilding.
